**Тема:** Организация рекламно-информационной работы коммерческой организации и оценка её эффективности

**Объект исследования:** ООО «Фаст Инжиниринг», г. Москва (ИНН 7727053382, ОГРН 1037739374507)

**Специальность:** 38.02.04 Коммерция (по отраслям), базовый уровень подготовки

**Учебное заведение:** АОЧУ ВО «Московский финансово-юридический университет — МФЮА»

**Учебный год:** 2025–2026

## Структура репозитория

- `methodical_recommendations.txt` — методические рекомендации МФЮА (полный текст), на которые опирается оформление работы.
- `thesis/` — главы и структурные элементы дипломной работы в формате Markdown.
  - `00_titulnyi_list.md` — титульный лист (Приложение №3 методички).
  - `01_zadanie.md` — задание на дипломную работу (Приложение №4).
  - `02_kalendarnyi_plan.md` — календарный план (Приложение №5).
  - `03_oglavlenie.md` — оглавление (Приложение №6).
  - `04_vvedenie.md` — введение.
  - `05_glava_1.md` — Глава 1. Теоретические основы рекламно-информационной работы и оценки её эффективности.
  - `06_glava_2.md` — Глава 2. Анализ организации рекламно-информационной работы ООО «Фаст Инжиниринг».
  - `07_glava_3.md` — Глава 3. Совершенствование рекламно-информационной работы ООО «Фаст Инжиниринг» и оценка её эффективности.
  - `08_zaklyuchenie.md` — заключение.
  - `09_spisok_istochnikov.md` — список использованных источников (≥ 20, по ГОСТ).
  - `10_prilozheniya.md` — приложения.
- `build/` — готовые сборки `.docx`, оформленные по требованиям МФЮА.
- `scripts/build_docx.py` — сборка единого файла дипломной работы в `.docx` с оформлением по методичке (Times New Roman 14, межстрочный 1,5, поля 30/10/20/20 мм, абзацный отступ 1,25 см, выравнивание по ширине, заголовки структурных элементов прописными по центру с новой страницы, нумерация страниц по центру нижнего поля).

## Требования оформления (из методички МФЮА, раздел 8)

- MS Word, шрифт Times New Roman, кегль 14.
- Межстрочный интервал 1,5; абзацный отступ 1,25 см; выравнивание по ширине.
- Поля: верхнее 20 мм, нижнее 20 мм, левое 30 мм, правое 10 мм.
- Объём работы: 60–70 страниц до списка источников; главы 1+2+3 — не менее 50 страниц.
- Оригинальность текста — не менее 60 %.
- Заголовки структурных элементов («ОГЛАВЛЕНИЕ», «ВВЕДЕНИЕ», названия глав, «ЗАКЛЮЧЕНИЕ», «СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ», «ПРИЛОЖЕНИЕ») — прописными буквами, по центру, без точки, с новой страницы.
- Заголовки подразделов и пунктов — строчными, с абзацного отступа.
- Нумерация страниц — арабскими, сквозная, по центру нижнего поля; на титульном листе номер не ставится, но он входит в общую нумерацию.

## Сборка

```bash
pip install python-docx
python3 scripts/build_docx.py
```

После сборки готовый файл будет в `build/diplom_fast_engineering.docx`.
